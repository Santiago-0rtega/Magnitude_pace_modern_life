B.1 What this tests

Protocol §3.7 (first analysis). ln M is estimated less stably when the two groups being compared are small, because the plug-in sampling variance can become unstable when between-group variation is small relative to within-group variation. To check that the main conclusions do not rest on poorly replicated contrasts, every included moderator model is refit after restricting the data to contrasts with total sample size \(n_1 + n_2 \geq 40\) — 5,253 of 7,237 contrasts. All other model structure (phylogeny, ref_id, priors, MCMC settings) is identical to the primary fit.

B.2 How it was fit

Fit on the compute server (totoro), not at render. Each model uses 4 chains × 4,000 iterations (2,000 warmup), adapt_delta = 0.97, max_treedepth = 15, cmdstanr. The book reads the cached summary tables only.

Code 
dat_n40 <- dat_es |> dplyr::filter(n_total >= 40)
phylo   <- prepare_phylo_and_data(dat_mod, A_full)          # phylogeny retained
formula <- build_ls_formula(moderator, has_phylogeny = phylo$has_phylo)
fit     <- fit_ls_model(
  phylo$dat_model, formula,
  build_ls_priors(formula, phylo$dat_model, phylo$V, A = phylo$A_mod),
  V = phylo$V, A = phylo$A_mod, mcmc_args = default_mcmc_args)

B.4 Reading the tables

Each moderator is shown as a raw location–scale coefficient table on the model’s default treatment coding: the Intercept row is the reference-level value and each other row is the difference from that reference. The matched primary coefficient is shown alongside. The Stability column compares the two: it reads consistent when the sensitivity and primary coefficients share sign and the same 95% credible-interval conclusion (both exclude or both include zero), and DIFFERS otherwise.

Overall: 4 of 36 moderator coefficients change their credible-interval conclusion relative to the primary fit.
