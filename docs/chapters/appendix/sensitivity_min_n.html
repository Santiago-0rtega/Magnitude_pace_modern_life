B.1 Recorded change

Small samples can make ln M and its plug-in sampling variance less stable. Following protocol §3.7, we therefore retained only contrasts with total sample size \(n_1 + n_2 \geq 40\).

NoteWhat changed—and what did not

Changed: the analysis includes 5,253 of 7,237 contrasts after applying the sample-size threshold.

Unchanged: the moderator definitions, phylogenetic effect, ref_id effect, priors, and MCMC settings match the primary models.

B.2 Model specification

Models were fit on the compute server (totoro), not while rendering this book. Each model uses 4 chains × 4,000 iterations (2,000 warmup), adapt_delta = 0.97, max_treedepth = 15, and the cmdstanr backend. This chapter reads cached summary tables only.

Code 
dat_n40 <- dat_es |> dplyr::filter(n_total >= 40)
phylo   <- prepare_phylo_and_data(dat_mod, A_full)
formula <- build_ls_formula(moderator, has_phylogeny = phylo$has_phylo)
fit     <- fit_ls_model(
  phylo$dat_model, formula,
  build_ls_priors(formula, phylo$dat_model, phylo$V, A = phylo$A_mod),
  V = phylo$V, A = phylo$A_mod, mcmc_args = default_mcmc_args)

B.4 Overall comparison

The comparison label uses a fixed rule: DIFFERS means that the posterior median changed sign or that the 95% credible interval changed between including and excluding zero. Consistent means neither occurred; it does not mean the two estimates are identical. Intercepts are omitted from the overall count.

Code 
cat("**Overall:** ", sens_stability_summary(variant), "\n")

Overall: 4 of 36 moderator coefficients change their credible-interval conclusion relative to the primary fit.
