19.1 Before you start

This chapter gives the setup steps in order. Run all commands from the project folder. Use the quick route to rebuild the web book from saved results. Use the full route to calculate the effect sizes and fit the models again.

ImportantUse the project folder

Open Magnitude_pace_modern_life.Rproj before running R code. Do not change the folder names. The code uses here::here() to find files from the project root.

19.2 Step 1 — Get the project

Download the repository from GitHub or clone it with Git:

git clone https://github.com/Santiago-0rtega/Magnitude_pace_modern_life.git
cd Magnitude_pace_modern_life

Keep the data/, Rdata/, chapters/, and _quarto.yml paths unchanged.

19.3 Step 2 — Install R packages

The project checks one package list in Scripts/00_packages.R. The list includes every non-base R package named in the book and analysis scripts, including ggbeeswarm and patchwork.

cran_packages <- c(
  "ape", "bayesplot", "brms", "cli", "cmdstanr", "coda", "dplyr",
  "emmeans", "ggbeeswarm", "ggplot2", "here", "httr2", "janitor",
  "kableExtra", "knitr", "orchaRd", "patchwork", "png", "posterior", "purrr",
  "quarto", "readr", "remotes", "rotl", "scales", "sessioninfo", "stringr", "tibble",
  "tidybayes", "tidyr", "tidyverse"
)
install.packages(setdiff(cran_packages, rownames(installed.packages())))

Install prepR4pcm from its source repository:

install.packages("remotes")
remotes::install_github("itchyshin/prepR4pcm")

Check the complete project list:

source(here::here("Scripts", "00_packages.R"))

No message means that the package check passed.

19.4 Step 3 — Install CmdStan

The Bayesian models use CmdStan through cmdstanr.

cmdstanr::install_cmdstan(cores = max(1, parallel::detectCores() - 1))
cmdstanr::cmdstan_version()

The model scripts use CPU chains. A GPU is not required.

19.5 Step 4 — Choose a route

19.5.1 Quick route: render saved results

Confirm that the main saved files exist:

required_files <- c(
  "Rdata/data_clean/proceed_clean_filtered.rds",
  "Rdata/effect_sizes/proceed_lnm_safe.rds",
  "Rdata/phylogeny/proceed_A_matrix.rds",
  "Rdata/tables/grid_summary_cache.rds"
)
missing_files <- required_files[!file.exists(required_files)]
if (length(missing_files)) stop("Missing: ", paste(missing_files, collapse = ", "))

Then move to Step 6.

19.5.2 Full route: rebuild analysis files

Run the work in this order:

  1. Prepare the data.
  2. Calculate SAFE lnM.
  3. Build the dependency structure.
  4. Build and align the phylogeny.
  5. Fit the model grid.
  6. Run the precompute scripts in Step 5 below.
  7. Create the publication figures.

The fitting scripts live in Scripts/ and run from the project root. Each one loads the fitting toolchain through Scripts/00_packages_fit.R and resolves every path with here::here(), so no path editing is needed:

Rscript Scripts/remote_rebuild_safe.R
Rscript Scripts/run_model_grid.R
Rscript Scripts/run_sensitivity.R
Rscript Scripts/aggregate_sensitivity.R

remote_rebuild_safe.R rebuilds the cleaned data and the SAFE lnM effect sizes. run_model_grid.R fits the moderator grid; run_model_grid_m07plus.R and the single-model run_m*.R scripts refit individual models. Fitting the full grid takes many hours and needs roughly 400 MB of disk per model.

The rendered book is read-only. Rebuild large files with the analysis scripts, not during a normal book render.

19.6 Step 5 — Prepare small files for the book

Every script builds its output paths with dir_out(), defined once in Scripts/01_paths.R. It writes to Rdata/ by default, so a local run puts files where the book already reads them and no copying is needed. To send output somewhere else, set options(pace.out_root = "outputs") before sourcing 01_paths.R.

After fitting models, run these scripts from the project root in this order:

Rscript Scripts/precompute_grid_summaries.R
Rscript Scripts/precompute_epred_draws.R
Rscript Scripts/precompute_emmeans_contrasts.R
Rscript Scripts/precompute_heterogeneity.R

These scripts convert large fitted models into small tables and prediction files.

A local run needs no copying. If the models were fitted on a separate compute server that writes to outputs/, copy the completed folders across instead:

Compute server Web-book project
outputs/epred_draws/ Rdata/epred_draws/
outputs/summaries/ Rdata/summaries/
outputs/tables/ Rdata/tables/
outputs/figures/ Rdata/figures/

Replace the matching files in Rdata/ only after every compute script finishes.

NoteFitted models are not in the repository

.gitignore excludes every .rds file, so a fresh clone contains the raw data, all scripts, and the small CSV and figure outputs, but none of the fitted models or cached draws. Take the quick route only if you already hold a copy of Rdata/; otherwise use the full route and refit.

19.7 Step 6 — Render the web book

quarto::quarto_render()

The website is written to docs/. Open docs/index.html to read the local copy. Missing saved results cause an error instead of starting a long fit.

## Before you start {#sec-reproducibility}

This chapter gives the setup steps in order. Run all commands from the project
folder. Use the **quick route** to rebuild the web book from saved results. Use
the **full route** to calculate the effect sizes and fit the models again.

::: {.callout-important title="Use the project folder"}
Open `Magnitude_pace_modern_life.Rproj` before running R code. Do not change the
folder names. The code uses `here::here()` to find files from the project root.
:::

## Step 1 — Get the project

Download the repository from GitHub or clone it with Git:

```bash
git clone https://github.com/Santiago-0rtega/Magnitude_pace_modern_life.git
cd Magnitude_pace_modern_life
```

Keep the `data/`, `Rdata/`, `chapters/`, and `_quarto.yml` paths unchanged.

## Step 2 — Install R packages

The project checks one package list in `Scripts/00_packages.R`. The
list includes every non-base R package named in the book and analysis scripts,
including `ggbeeswarm` and `patchwork`.

```r
cran_packages <- c(
  "ape", "bayesplot", "brms", "cli", "cmdstanr", "coda", "dplyr",
  "emmeans", "ggbeeswarm", "ggplot2", "here", "httr2", "janitor",
  "kableExtra", "knitr", "orchaRd", "patchwork", "png", "posterior", "purrr",
  "quarto", "readr", "remotes", "rotl", "scales", "sessioninfo", "stringr", "tibble",
  "tidybayes", "tidyr", "tidyverse"
)
install.packages(setdiff(cran_packages, rownames(installed.packages())))
```

Install `prepR4pcm` from its source repository:

```r
install.packages("remotes")
remotes::install_github("itchyshin/prepR4pcm")
```

Check the complete project list:

```r
source(here::here("Scripts", "00_packages.R"))
```

No message means that the package check passed.

## Step 3 — Install CmdStan

The Bayesian models use CmdStan through `cmdstanr`.

```r
cmdstanr::install_cmdstan(cores = max(1, parallel::detectCores() - 1))
cmdstanr::cmdstan_version()
```

The model scripts use CPU chains. A GPU is not required.

## Step 4 — Choose a route

### Quick route: render saved results

Confirm that the main saved files exist:

```r
required_files <- c(
  "Rdata/data_clean/proceed_clean_filtered.rds",
  "Rdata/effect_sizes/proceed_lnm_safe.rds",
  "Rdata/phylogeny/proceed_A_matrix.rds",
  "Rdata/tables/grid_summary_cache.rds"
)
missing_files <- required_files[!file.exists(required_files)]
if (length(missing_files)) stop("Missing: ", paste(missing_files, collapse = ", "))
```

Then move to Step 6.

### Full route: rebuild analysis files

Run the work in this order:

1. [Prepare the data](01_data_preparation.qmd).
2. [Calculate SAFE lnM](02_lnm_effect_sizes.qmd).
3. [Build the dependency structure](04_dependency_structure.qmd).
4. [Build and align the phylogeny](04b_phylogeny.qmd).
5. [Fit the model grid](05_location_scale_model_grid.qmd).
6. Run the precompute scripts in Step 5 below.
7. [Create the publication figures](08_publication_figures.qmd).

The fitting scripts live in `Scripts/` and run from the project root. Each one
loads the fitting toolchain through `Scripts/00_packages_fit.R` and resolves
every path with `here::here()`, so no path editing is needed:

```bash
Rscript Scripts/remote_rebuild_safe.R
Rscript Scripts/run_model_grid.R
Rscript Scripts/run_sensitivity.R
Rscript Scripts/aggregate_sensitivity.R
```

`remote_rebuild_safe.R` rebuilds the cleaned data and the SAFE lnM effect sizes.
`run_model_grid.R` fits the moderator grid; `run_model_grid_m07plus.R` and the
single-model `run_m*.R` scripts refit individual models. Fitting the full grid
takes many hours and needs roughly 400 MB of disk per model.

The rendered book is read-only. Rebuild large files with the analysis scripts,
not during a normal book render.

## Step 5 — Prepare small files for the book

Every script builds its output paths with `dir_out()`, defined once in
`Scripts/01_paths.R`. It writes to `Rdata/` by default, so a local run
puts files where the book already reads them and no copying is needed. To send
output somewhere else, set `options(pace.out_root = "outputs")` before sourcing
`01_paths.R`.

After fitting models, run these scripts from the project root in this order:

```bash
Rscript Scripts/precompute_grid_summaries.R
Rscript Scripts/precompute_epred_draws.R
Rscript Scripts/precompute_emmeans_contrasts.R
Rscript Scripts/precompute_heterogeneity.R
```

These scripts convert large fitted models into small tables and prediction
files.

A local run needs no copying. If the models were fitted on a separate compute
server that writes to `outputs/`, copy the completed folders across instead:

| Compute server | Web-book project |
|---|---|
| `outputs/epred_draws/` | `Rdata/epred_draws/` |
| `outputs/summaries/` | `Rdata/summaries/` |
| `outputs/tables/` | `Rdata/tables/` |
| `outputs/figures/` | `Rdata/figures/` |

Replace the matching files in `Rdata/` only after every compute script finishes.

::: {.callout-note title="Fitted models are not in the repository"}
`.gitignore` excludes every `.rds` file, so a fresh clone contains the raw data,
all scripts, and the small CSV and figure outputs, but none of the fitted models
or cached draws. Take the quick route only if you already hold a copy of
`Rdata/`; otherwise use the full route and refit.
:::

## Step 6 — Render the web book

```r
quarto::quarto_render()
```

The website is written to `docs/`. Open `docs/index.html` to read the local
copy. Missing saved results cause an error instead of starting a long fit.
