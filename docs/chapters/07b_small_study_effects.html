16.1 Why sample size, rather than sampling error?

We assess whether estimated effect magnitudes vary systematically with study size. Such a pattern is a small-study effect: it can be consistent with publication bias, but it can also arise from genuine heterogeneity or design differences. It is therefore a diagnostic, not a direct test of the publication process.

The usual Egger regression uses an effect’s sampling standard error as the predictor. For lnM, however, the effect and its estimated standard error share underlying variance components. Their structural dependence can create artefactual asymmetry. Following the lnM worked example and Nakagawa et al. (2022), we instead use a predictor calculated only from the two group sample sizes.

For each contrast, the harmonic effective sample size is

\[ n_0 = \frac{n_1 n_2}{n_1 + n_2}. \]

We fit two related models:

  1. \(1/\sqrt{n_0}\) is an SE analogue; its slope is the primary diagnostic for small-study effects.
  2. \(1/n_0\) is a variance analogue; its intercept at \(1/n_0=0\) is an infinite-sample, bias-adjusted estimate. We treat this as a conditional sensitivity estimate rather than an automatic replacement for the primary meta-analytic mean.

16.1.1 Constructing the predictors

The two predictors are calculated directly from the original group sample sizes. Neither uses the observed lnM estimate or its sampling variance.

Code 
diagnostic_data <- readRDS(
  here::here("Rdata", "effect_sizes", "proceed_lnm_safe.rds")
) |>
  dplyr::filter(
    is.finite(n1), n1 > 0,
    is.finite(n2), n2 > 0
  ) |>
  dplyr::mutate(
    n0   = (n1 * n2) / (n1 + n2),
    n_se = 1 / sqrt(n0),
    n_v  = 1 / n0
  )

16.2 Model structure

Both models use SAFE lnM as the response and retain the analysis’s known sampling variances. Random intercepts account for clustering by reference, phylogenetically correlated species, and effect-size record. Thus the diagnostic changes the fixed predictor while preserving the main sources of non-independence.

Code 
diagnostic_data <- prepare_small_study_data()

fit_se <- metafor::rma.mv(
  yi = yi_lnM_safe,
  V = vi_lnM_safe,
  mods = ~ n_se,
  random = list(
    ~ 1 | ref_id,
    ~ 1 | sp_ncbi,
    ~ 1 | es_id_model
  ),
  R = list(sp_ncbi = diagnostic_data$A),
  Rscale = "cor",
  method = "REML",
  test = "t",
  sparse = TRUE,
  data = diagnostic_data$data
)

fit_v <- metafor::rma.mv(
  yi = yi_lnM_safe,
  V = vi_lnM_safe,
  mods = ~ n_v,
  random = list(
    ~ 1 | ref_id,
    ~ 1 | sp_ncbi,
    ~ 1 | es_id_model
  ),
  R = list(sp_ncbi = diagnostic_data$A),
  Rscale = "cor",
  method = "REML",
  test = "t",
  sparse = TRUE,
  data = diagnostic_data$data
)

16.4 Diagnostic plot

The two panels are constructed from the cached models and joined with patchwork. Bubble area represents sampling precision, \(1/\mathrm{SE}\).

Code 
diagnostic_data <- prepare_small_study_data()

p_se <- build_small_study_figure(
  small_study_fit$fit_se,
  diagnostic_data$data,
  predictor = "n_se",
  bubble_fill = "#DC143C",
  line_colour = "#DC143C"
)

p_v <- build_small_study_figure(
  small_study_fit$fit_v,
  diagnostic_data$data,
  predictor = "n_v",
  bubble_fill = "#FF8C00",
  line_colour = "#8B4500"
) +
  ggplot2::theme(legend.position = "none")

p <- ((p_se + p_v) / patchwork::guide_area()) +
  patchwork::plot_layout(heights = c(1, 0.10), guides = "collect") +
  patchwork::plot_annotation(tag_levels = "A", tag_suffix = ")") &
  ggplot2::theme(
    legend.position = "bottom",
    legend.justification = "center",
    plot.tag = ggplot2::element_text(face = "bold", size = 14),
    plot.tag.position = c(0.01, 0.99)
  )

ggplot2::ggsave(
  here::here("Rdata", "figures", "publication", "small_study_effects.png"),
  p, width = 13, height = 6, dpi = 300, bg = "white"
)
Code 
knitr::include_graphics(figure_path)
Note

The infinite-sample intercept is an extrapolation to \(1/n_0=0\), outside the observed finite-sample data. It is most useful as a sensitivity analysis when the slope diagnostic indicates small-study effects and the model is otherwise well specified.
