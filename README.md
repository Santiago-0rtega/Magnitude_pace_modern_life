# Human disturbance and the magnitude and predictability of phenotypic divergence

Code, data and computational supplement for the manuscript of the same title (authors withheld for double-anonymous peer review).

## Summary

This repository contains a preregistered meta-analytic reanalysis of the PROCEED v6.2 rates database. For each population contrast, the magnitude of phenotypic divergence is expressed as the effect size lnM and estimated with the SAFE estimator. lnM values are analysed with Bayesian phylogenetic location–scale meta-regressions (`brms` with the `cmdstanr` backend), which model both the mean (location) and the residual heterogeneity (scale) of lnM. Moderators are fitted one per model: disturbance context (primary), comparison design, elapsed time (log10 years; log10 generations), trait type and study type (phenotypic vs genetic). Prespecified sensitivity analyses (minimum sample size N ≥ 40, no phylogenetic random effect, added study-system random effect) and non-preregistered checks (moderators adjusted for elapsed time, a leave-one-reference-out refit) are reported in the appendices of the book.

**Definition of lnM.** lnM is the log ratio of the estimated between-group standard deviation to the pooled within-group standard deviation of a two-group comparison, lnM = ln(s_B / s_W). It measures the magnitude of divergence between two group means relative to within-group variation and does not retain the direction of the difference. The full derivation is given in `chapters/02_lnm_effect_sizes.qmd`.

## Data

- `data/PROCEEDv6.2_RatesDB.csv`: the complete, unfiltered PROCEED v6.2 rates database. Source: Gotanda K.M. & Gorné L.D. (2026) PROCEED version 6.2. Borealis. https://doi.org/10.5683/SP3/NXSL3Q. Variable definitions are given in the PROCEED metadata distributed with that dataset.
- `.gitignore` excludes every `.rds` file. The following derived objects are therefore **not** in the repository and are regenerated by the pipeline: the cleaned data (`Rdata/data_clean/`), SAFE lnM estimates (`Rdata/effect_sizes/`), the phylogenetic tree, correlation matrix and name map (`Rdata/phylogeny/*.rds`), fitted models (`Rdata/models/`), posterior prediction caches (`Rdata/epred_draws/`), summary caches (`Rdata/summaries/`), and the `.rds` bundles in `Rdata/tables/` and `Rdata/figures/`.
- Tracked summary outputs (CSV) in `Rdata/tables/`: descriptive counts (`counts_by_*.csv`, `descriptive_overview.csv`, `m00_disturbance_taxa_trait_percent.csv`), SAFE diagnostics (`safe_lnm_diagnostics.csv`), dependency tables (`dependency_*.csv`), model-grid effects, diagnostics and status (`location_effects_all_moderators.csv`, `scale_effects_all_moderators.csv`, `model_diagnostics_all_moderators.csv`, `model_grid_status.csv`), marginal means and pairwise contrasts (`contrasts/`), primary-fit fixed effects and diagnostics (`primary/`), moderator associations (`moderator_associations/`), sensitivity and leave-one-reference-out tables (`sensitivity/`; per-model parts in `sensitivity/parts/`), time-adjusted model diagnostics (`additive_diagnostics.csv`), heterogeneity decomposition (`heterogeneity_m00.csv`), small-study diagnostics (`small_study_effects.csv`), data-flow counts (`data_flow_counts.csv`) and included references (`included_references.csv`). `Rdata/phylogeny/unmatched_species.csv` lists species names not matched to the phylogeny.

## How to reproduce

Run all commands from the repository root (open `Magnitude_pace_modern_life.Rproj`); paths are resolved with `here::here()`. Step-by-step instructions are also given in the book chapter "Reproduce this analysis" (`chapters/09_reproducibility.qmd`).

**1. Install R packages.** The package list is in `Scripts/00_packages.R`.

```r
install.packages(c(
  "ape", "bayesplot", "brms", "cli", "coda", "dplyr", "emmeans",
  "ggbeeswarm", "ggplot2", "here", "httr2", "janitor", "kableExtra", "knitr",
  "metafor", "patchwork", "png", "posterior", "purrr", "quarto", "readr",
  "remotes", "rotl", "scales", "sessioninfo", "stringr", "tibble",
  "tidybayes", "tidyr", "tidyverse"
))
install.packages("cmdstanr", repos = c("https://stan-dev.r-universe.dev", getOption("repos")))
remotes::install_github("daniel1noble/orchaRd")   # SAFE lnM estimator
remotes::install_github("itchyshin/prepR4pcm")    # species-name reconciliation
source(here::here("Scripts", "00_packages.R"))     # dependency check
```

**2. Install CmdStan.**

```r
cmdstanr::install_cmdstan()
cmdstanr::cmdstan_version()
```

**3. Regenerate the derived objects.** Because `.rds` files are not tracked, a fresh clone must rebuild them before the book can render. Model fitting was done outside the book on a remote Linux compute server; fitting takes hours per model. In order:

```bash
Rscript Scripts/remote_rebuild_safe.R      # cleaned data + SAFE lnM
# phylogeny: set recompute_phylogeny <- TRUE in chapters/04b_phylogeny.qmd and run it (needs internet)
Rscript Scripts/run_model_grid.R           # or: Rscript Scripts/remote_fit_one_primary.R MODEL_ID
Rscript Scripts/run_sensitivity.R
Rscript Scripts/aggregate_sensitivity.R
Rscript Scripts/precompute_grid_summaries.R
Rscript Scripts/precompute_epred_draws.R
Rscript Scripts/precompute_emmeans_contrasts.R
Rscript Scripts/precompute_heterogeneity.R
```

The launchers `remote_rebuild_then_refit.sh`, `remote_run_small_study_parallel.sh`, `remote_run_small_study_brms_parallel.sh` and `remote_refit_small_study_brms_parallel.sh` run the corresponding `Scripts/remote_*.R` fits in parallel; each changes to a fixed server working directory that must be edited before use. If outputs are written to a separate `outputs/` tree (`options(pace.out_root = "outputs")`), copy its `epred_draws/`, `summaries/`, `tables/` and `figures/` folders into `Rdata/` before rendering.

**4. Render the book.**

```bash
quarto render
```

Output is written to `docs/` (open `docs/index.html`). The pre-render step `Rscript Scripts/21_validate_summary_artifacts.R` runs first, so `Rscript` must be available to Quarto (on the PATH, or via the `QUARTO_R` environment variable). The render stops with an error if required cached objects are missing; it never starts model fitting.

**Configuration flags** (set at the top of each chapter; all default to `FALSE`, i.e. read cached objects):

| Flag | Chapter | Effect when `TRUE` |
|---|---|---|
| `rebuild_clean_data` | `chapters/01_data_preparation.qmd` | Rebuilds the cleaned, filtered dataset from the raw CSV |
| `recompute_effect_sizes` | `chapters/02_lnm_effect_sizes.qmd` | Recomputes SAFE lnM for all contrasts (slow) |
| `recompute_phylogeny` | `chapters/04b_phylogeny.qmd` | Rebuilds the phylogeny and correlation matrix (requires internet) |
| `refit_models` | `chapters/05_location_scale_model_grid.qmd` | Refits all location–scale models from scratch with CmdStan (hours per model) |
| `rebuild_grid` | `chapters/05_location_scale_model_grid.qmd` | Regenerates the grid summary tables by loading every fitted model |
